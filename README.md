# Sudeep Kumar Surya — Personal Portfolio

> A modern, responsive, high-performance personal developer portfolio showcasing skills, featured projects, and contact information.

---

## 🌟 Overview

Welcome to the personal portfolio website of **Sudeep Kumar Surya**. This portfolio serves as a digital showcase highlighting technical expertise, full-stack software development projects, design aesthetics, and professional achievements.

### Key Highlights
- **Modern & Premium Aesthetics**: Dark mode first, fluid glassmorphism, responsive micro-interactions, and modern typography.
- **Project Showcase**: Rich interactive previews, tech-stack tagging, live demo links, and GitHub repository links.
- **Skills & Tech Stack**: Interactive categorised display (Frontend, Backend, Tools & DevOps, Databases).
- **Contact & Connect**: Direct contact form, quick links to GitHub, LinkedIn, and email.
- **Performance & SEO**: Built with semantic HTML5, zero-bloat modular structure, responsive mobile-first layouts, and fast loading times.

---

## 🛠️ Tech Stack

- **Core**: HTML5, Modern Vanilla JavaScript (ES6+)
- **Styling**: Vanilla CSS3 (Custom design system, CSS variables, glassmorphism, Flexbox & Grid)
- **Typography & Icons**: Google Fonts (Inter / Outfit / Plus Jakarta Sans), Lucide / SVG Icons
- **Deployment**: GitHub Pages / Vercel / Netlify

## 🚀 Getting Started

### Prerequisites
- Any modern web browser (Chrome, Firefox, Edge, Safari)
- Optional: Live Server extension in VS Code or lightweight local server (`npx serve`)

### Running Locally

1. Clone or navigate to the repository:
   ```bash
   cd Portfolio
   ```

2. Open with a local server or directly view:
   ```bash
   # Option 1: Using npx serve or python
   npx serve .
   # or
   python -m http.server 3000
   ```
   Or simply open `index.html` in your favorite web browser.
